CHICAGO VISUAL REFRESH — NOVEMBER 3, 2026

History line: CHICAGO, 1952 / GRAPEVINE, 2002.
Source: https://weinbergersdeli.com/story (checked 2026-11-03).
Dan's official story states the brand was founded in Chicago in 1952 and opened
its Grapevine deli in 2002. The 1928 Italian Beef recipe date is not a founding date.
The original logo and food photography remain unaltered. The three Chicago
shortcuts reference canonical existing items: italian-beef-a3od,
chicago-dog-JTAI, and maxwell-street-polish-dog-kxOH.

MENU PHOTOGRAPHY AND WEBSITE SHARE ARTWORK — NOVEMBER 20, 2026

The 125 menu entries with imagery use the deli's published files. media.js
records the item ID, original catalogue path, official source URL and each
delivery size. The four assets in counter-photos use the following crops,
in pixels from the top left of each unresized source.

Gayle's Super Reuben: 1920 x 1440 original, crop (0,70), 1920 x 1350.
Jaybird's Sandwich: 1440 x 1920 original, crop (0,320), 1440 x 1430.
Italian Beef: 540 x 720 original, crop (0,158), 540 x 546.
Weinberger Reuben: 960 x 960 deli clipping, crop (0,0), 960 x 720.
The first three received small exposure and color adjustments. The clipping
retains its original labels and title. All four use only original pixels.

Website link image: weinbergers-sandwich-counter-ticket-20261120-r2.png.
The photograph is the deli's published five-basket overhead spread described
below. The ticket uses the existing smooth rendering of the original logo.
The editable layout is design/social-card.html in the source package.

iPhone link image: weinbergers-iphone-ordering-mark-cuban-20261120-r2.png.
The phone contains a 390 by 844 capture of the final mobile ordering page;
its cover uses the deli's published Mark Cuban sandwich photograph. The

design/iphone-social-card.html in the source package. No generated food or
storefront imagery appears in either link image.
